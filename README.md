# 🏦 AI Banking Assistant

## 📌 Project Description

AI Banking Assistant is an interactive **demo banking application** developed using **Python and Streamlit**. It provides a simple and user-friendly interface where users can explore common banking services through interactive buttons and an AI-style chatbot.

The application includes **demo account details, balance checking, transaction history, UPI payments, money transfer, card services, ATM services, loans, deposits, security features, IFSC information, and customer support**.

All account information and transactions in this project are **fictional and used only for educational and demonstration purposes**. No real banking transactions are performed.

## ✨ Features

* 👤 Demo Account Details
* 💰 Balance Checking
* 📊 Transaction History
* 📱 UPI Payment Simulation
* 💸 Money Transfer Simulation
* 💳 Card Services
* 🏧 ATM Services
* 🏦 Loan Information
* 💵 Deposit Services
* 🔐 Security Center
* 🏢 IFSC Information
* 📞 Customer Support
* 🤖 AI Banking Chatbot
* 🔑 Demo Account Verification
* 📈 Dynamic Demo Balance and Transactions
* 🔄 Reset Demo Function

## 🛠️ Technologies Used

* Python
* Streamlit
* HTML/CSS
* Python Session State

## 🎯 Purpose

The main purpose of this project is to demonstrate how a **banking application interface and chatbot can be developed using Python and Streamlit** while providing an interactive experience for users.

> ⚠️ **Note:** This is an educational demo project. It does not connect to any real bank and does not process real money, payments, passwords, OTPs, or banking credentials.
